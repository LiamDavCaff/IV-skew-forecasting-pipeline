# IV Skew Forecasting Pipelines

## Monthly, Daily and Cross-Market Analysis

This repository contains the empirical forecasting pipeline used to evaluate whether implied volatility (IV) skew measures predict future equity-index excess returns under a consistent out-of-sample (OOS) forecasting framework.

The analysis examines how return predictability varies across alternative:

- IV skew definitions;
- forecast horizons;
- estimation-window lengths;
- rolling and expanding estimation procedures;
- daily and monthly sampling frequencies; and
- equity markets.

Where applicable, the OOS framework uses:

- rolling or expanding predictive regressions with no look-ahead bias;
- like-for-like rolling or expanding historical-mean benchmarks;
- Campbell--Thompson out-of-sample \(R^2\);
- Clark--West tests for nested forecast comparisons; and
- Benjamini--Hochberg false-discovery-rate (BH-FDR) adjustment of Clark--West p-values using the testing families defined in the analysis.

The repository contains:

- **Monthly forecasting pipeline**  
  Panel construction → exploratory analysis → in-sample regressions → OOS forecasts → heatmaps → cumulative OOS \(R^2\) paths → rolling/expanding coefficient analysis.

- **Daily forecasting pipeline**  
  Daily OOS forecasting across selected IV skew predictors, forecast horizons and estimation windows.

- **Cross-market forecasting pipeline**  
  Monthly OOS forecasting across multiple international equity indices using a common sample period.

- **IV surface visualisation**  
  An example script for constructing a three-dimensional IV surface for a selected date.

> **Important:** The empirical input datasets are constructed from Bloomberg data and are **not included** in this repository because redistribution is restricted by the applicable Bloomberg licence. Selected machine-readable statistical result grids generated by the forecasting pipelines are included to support verification and reproducibility of the reported empirical results. Raw Bloomberg observations remain excluded.

## Repository structure

### `scripts/`

Contains the main empirical analysis scripts.

- `monthly_forecasting_pipeline.R`  
  Builds the monthly panel, performs exploratory and in-sample analysis, estimates OOS forecasting models, generates heatmaps and cumulative \(R^2_{\mathrm{OOS}}\) paths, and evaluates rolling/expanding coefficients.

- `daily_forecasting_pipeline.R`  
  Runs the daily-frequency OOS forecasting analysis.

- `cross_market_pipeline.R`  
  Runs the multi-index monthly OOS forecasting analysis using a common cross-market sample period.

- `spx_surface_builder.R`  
  Optional IV-surface visualisation example.

### `bloomberg_scripts/`

Contains the scripts used to extract and construct the Bloomberg datasets used by the empirical pipelines.

These scripts document, where applicable:

- Bloomberg securities;
- field identifiers;
- maturity and moneyness overrides;
- sample dates; and
- extraction and data-construction procedures.

These scripts must be run first to generate the required local `.rds` files in `data/`.

### `data/`

Local input datasets are stored here.

Raw Bloomberg datasets are deliberately excluded from Git using `.gitignore`. Users wishing to reproduce the analysis must obtain the required Bloomberg data through their own appropriately licensed access.

### `outputs/`

Generated figures and tables are written here.

Most generated outputs remain ignored by Git. Selected machine-readable statistical result grids are intentionally tracked to allow the numerical forecasting results reported in the dissertation to be independently inspected.

## Quick start

### 1. Generate the Bloomberg datasets

Run the appropriate scripts in:

```text
bloomberg_scripts/
```

These scripts create the required `.rds` files in:

```text
data/
```

Users without appropriately licensed Bloomberg access will not be able to recreate the Bloomberg source datasets directly.

### 2. Run the empirical pipelines

From the repository root:

```r
source("scripts/monthly_forecasting_pipeline.R")
source("scripts/daily_forecasting_pipeline.R")
source("scripts/cross_market_pipeline.R")
```

Optional IV-surface visualisation:

```r
source("scripts/spx_surface_builder.R")
```

### 3. Generated outputs

The principal generated-output locations are:

```text
outputs/monthly/figures/
outputs/monthly/tables/

outputs/daily/figures/
outputs/daily/tables/01_oos/

outputs/cross_market/figures/
outputs/cross_market/tables/01_oos/
outputs/cross_market/tables/02_appendix/
```

Most generated figures and ancillary tables are ignored by Git.

## Machine-readable result grids

To support verification of the dissertation's empirical findings, selected derived statistical outputs are committed to the repository in CSV format.

### Monthly analysis

#### In-sample results

```text
outputs/monthly/tables/02_insample/Tab7_insample_results_long.csv
outputs/monthly/tables/02_insample/Tab7_insample_controls_vix_results_long.csv
```

#### Out-of-sample results

```text
outputs/monthly/tables/03_oos/monthly_oos_expanding_results.csv
outputs/monthly/tables/03_oos/monthly_oos_rolling_results.csv
```

### Daily analysis

```text
outputs/daily/tables/01_oos/daily_oos_expanding_results.csv
outputs/daily/tables/01_oos/daily_oos_rolling_results.csv
```

### Cross-market analysis

```text
outputs/cross_market/tables/01_oos/cross_market_oos_expanding_results.csv
outputs/cross_market/tables/01_oos/cross_market_oos_rolling_results.csv
```

The OOS result grids contain the relevant model identifiers and derived forecasting statistics, including where applicable:

- predictor;
- forecast horizon;
- estimation-window length;
- benchmark specification;
- rolling/expanding estimation procedure;
- out-of-sample \(R^2\);
- Clark--West test statistic;
- raw Clark--West p-value;
- average estimated coefficient;
- primary BH-FDR adjusted q-value; and
- broader global BH-FDR robustness adjustment.

The primary multiple-testing family used for inference follows the definition specified for each analysis in the dissertation and corresponding analysis script. Broader global adjustments are retained in the machine-readable grids as robustness diagnostics where calculated.

These CSV files contain **derived statistical results only** and do not contain the underlying Bloomberg observations.

## Bloomberg data and licensing

The empirical source data used in this project were obtained from Bloomberg.

Raw Bloomberg observations and proprietary Bloomberg documentation are not redistributed through this repository due to applicable licensing restrictions.

The repository therefore distinguishes between:

1. **Source data**  
   Proprietary Bloomberg observations required to run the empirical analysis. These are excluded from the public repository.

2. **Extraction and analysis code**  
   The Bloomberg extraction scripts and full empirical forecasting pipelines are included.

3. **Derived statistical result grids**  
   Selected regression and forecasting outputs are provided in machine-readable CSV format to support verification of the reported empirical results.

4. **Generated figures and ancillary tables**  
   These are generally excluded from the public repository unless required for reproducibility.

Users wishing to reproduce the analysis must obtain the required source data through their own appropriately licensed Bloomberg access and generate the local `.rds` files using the supplied extraction scripts.

## Reproducibility

The repository is designed to provide the analysis code, extraction specifications and machine-readable statistical outputs required to inspect the empirical workflow while respecting Bloomberg licensing restrictions.

For the final archived version of the dissertation analysis, the repository should be identified by:

- a fixed GitHub release/tag;
- the associated Git commit hash;
- this README;
- `sessionInfo.txt`; and
- the machine-readable result grids listed above.

The release/tag and commit hash provide a fixed reference to the exact version of the code and outputs corresponding to the corrected dissertation.
